# Myntra Clone 🛍️

A clean, responsive frontend-only clone of the Myntra e-commerce website. This project focuses on replicating the core UI/UX of Myntra to showcase modern web design skills.

## 🚀 Live Demo
Check out the live project here: [https://github.io](https://dhavalantala.github.io/myntra_clone/)

## ✨ Key Features
*   **Fully Responsive:** Optimized for mobile, tablet, and desktop views.
*   **Interactive Header:** Navigation for Men, Women, Kids, Home & Living, and Beauty.
*   **Product Displays:** High-quality visual layouts for products and banners.
*   **Action Icons:** Functional-looking Wishlist, Bag, and Profile sections using **Bootstrap Icons**.

## 🛠️ Tech Stack
*   **HTML5:** Page structure and semantic elements.
*   **CSS3:** Custom styling for layout and animations.
*   **Bootstrap:** Utilized for a responsive grid system and integrated icons.

## 🏗️ Installation & Setup
To run this project locally:
1.  **Clone the repository:**
    ```bash
    git clone https://github.com
    ```
2.  **Navigate to the folder:**
    ```bash
    cd myntra_clone
    ```
3.  **Open index.html** in your preferred web browser.
